# 🏛️ Grievance Portal - Automated Petition Handler

An AI-powered grievance management system built with FastAPI.

## Features
- 📝 File and track grievances online
- 🤖 AI-powered classification using RAG
- 📱 SMS notifications via Twilio
- 🖼️ Image & document analysis with EasyOCR
- 📊 Admin dashboard for officers

## Tech Stack
- **Backend:** FastAPI (Python)
- **AI:** Groq LLM, EasyOCR, RAG Classifier
- **Database:** MongoDB + MySQL
- **SMS:** Twilio
